# 示波器玩具

一个中文、手机优先的纯前端网页示波器玩具。暖纸白外壳 + 深色示波器网格屏幕，
用来在手机上玩波形、PWM、李萨如图形、噪声与 RC 低通滤波。

## 本地打开

无需安装任何依赖、无需构建：

1. 下载本项目文件夹；
2. 直接双击 `index.html` 用浏览器打开即可；

或用任意静态服务器：

```bash
cd /workspace/shiboqi
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

运行测试（Node 内置 test runner，无需 npm）：

```bash
node --test tests/*.test.js
```

## 功能

- **双通道信号源 CH1 / CH2**：正弦 / 方波 / 三角 / 锯齿，
  频率 1 Hz – 5 kHz（对数滑块）、幅度 0 – 5 V、直流偏置 ±5 V、
  方波占空比 5% – 95%（可演示 PWM）、CH2 相位 ±180°。
- **YT 模式**：横轴时间、纵轴电压，CH1 上升沿触发，时基 0.5 – 200 ms/div，
  伏/格 0.5 / 1 / 2 V/div，触发电平 ±5 V，找不到边沿时自由滚动。
- **X-Y 模式**：李萨如图形（两路同频相位 90° 时为圆）。
- **自动测量**：频率、周期、峰峰值 Vpp、有效值 Vrms，实时刷新，
  单位自动换算（Hz / kHz、ms / μs）。
- **噪声 + RC 低通滤波**：可调高斯噪声（默认强度 σ ≈ 0.15 V），
  一阶 RC 低通（RC = 2 ms，截止约 80 Hz），每通道独立状态，暂停不清空。
- **运行 / 暂停**：暂停时冻结波形与滤波器状态。
- **设置持久化**：所有控件值自动保存到 localStorage（键前缀 `shiboqi-`），
  刷新后恢复。

## 默认演示场景

打开即见：CH1 正弦 50 Hz 2 V，CH2 正弦 50 Hz 2 V 相位 90°，
5 ms/div、1 V/div、触发 0 V、YT 模式运行中，噪声与滤波关闭。

试试：CH1 换方波 + 占空比 20% 看 PWM；切 X-Y 看李萨如圆；
开噪声再开滤波看毛刺被抹平。

## 技术说明

纯 Vanilla HTML / CSS / JS，无框架、无构建、无运行时依赖。
`js/waves.js`、`js/measure.js`、`js/filter.js` 为浏览器 / Node 通用纯模块，
由 `node --test` 覆盖；`js/scope.js` 提供采样缓冲、触发与绘制辅助；
`js/app.js` 负责界面绑定与 rAF 动画循环。
